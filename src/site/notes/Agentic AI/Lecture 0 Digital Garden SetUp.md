What is Digital Garden in obsidian ?

A Digital Garden is a collection of interconnected notes is Obsidian that you continuously update, improve, and grow over time.

How to setup Digital Garden? 

1. Download the Obsidian application on system like Window or MAC. 
![Obsidian Download.png](/img/user/Agentic%20AI/Obsidian%20Download.png)

2. Click on Download wait to complete download
3. Double click on setup file that you have downloaded and follow the default step to complete installation.
4. Open the Obsidian 
5. Go to setting -> Community Plugins
![Obsidian Setting menu.png](/img/user/Agentic%20AI/Obsidian%20Setting%20menu.png)

6.  Turn off Restricted mode
7. Click on Browser and Search for **Digital Garden**
8. Click on Install and Enable
9. Go to Digital Garden plugin and click on option menu 
![Option menu.png](/img/user/Agentic%20AI/Option%20menu.png)

10.  GitHub repo Name  "type or past name of repository"
11. GitHub Username "type or past name of GitHub login"
12. GitHub token "type or past token generated"
![configure the GitHub.png](/img/user/Agentic%20AI/configure%20the%20GitHub.png)
13. Past the token which we have generated in GitHub token.


**Create a GitHub Repository**
1. Sign in to GitHub.
2. Create a new repository (for example, `digital-garden`).
3. Keep it public unless you have a reason to make it private.
![GitHub Creating Repository.png](/img/user/Agentic%20AI/GitHub%20Creating%20Repository.png)
4. Select setting menu from GitHub Profile Icon
5. Select developer setting
6. Select the personal access tokens -> Fine-grained tokens
7. Click on Generate new token
8. Give Token Name and Description
9. Change the Expiration of Token
10. Change the Repository access "only select repositories"
11. Add permission like  "Action", "Content", "Metadata",  "Page", "Pull request" 
12. Change the permission from Read-only to Read and write
13. Click to Generate token
