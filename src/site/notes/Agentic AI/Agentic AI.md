What is Agentic AI?

Agentic AI is Artificial Intelligence that can autonomously plan, make decisions and perform task  to achieve a goal with minimal human guidance. 






**Create a GitHub Repository**
1. Sign in to GitHub.
2. Create a new repository (for example, `digital-garden`).
3. Keep it public unless you have a reason to make it private.
![GitHub Creating Repository.png](/img/user/Agentic%20AI/Image/GitHub%20Creating%20Repository.png)
4. Select setting menu from GitHub Profile Icon
5. Select developer setting
6. Select the personal access tokens -> Fine-grained tokens
7. Click on Generate new token
8. Give Token Name and Description
9. Change the Expiration of Token
10. Change the Repository access "only select repositories"
11. Add permission like  "Action", "Content", "Metadata",  "Page", "Pull request" 
12. Change the permission from Read-only to Read and write
13. Click to Generate token
