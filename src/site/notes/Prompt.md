**What is Prompt ?**
 Prompt engineering is the practice of designing, testing, and improving instructions given to an AI model to get more useful, accurate, and consistent results.

**Why Prompt Engineering Matter ?**
A useful prompt often contains these components:
Role + Task + Context + Constraints + Output Format
**Example** :
Role: You are a study tutor.
Task: Explain photosynthesis.
Context: The learner is a beginner.
Constraints: Use simple language and avoid unnecessary technical terms.
Output: Give a short explanation followed by 3 key points.

**Core Elements of a Good Prompt**
1. Role - Tell the AI what perspective or expertise to use.
2. Task - Clearly state what you want the AI to do.
3. Context - Give information that helps the AI understand the situation.
4. Constraints - Specify limits or requirements.
5. Output Format - Tell the AI how you want the answer structured.
_____
**Summary**
Prompt engineering = designing and refining instructions to help AI produce better, more reliable, and more useful outputs.
