**What is Vercel ?**

A cloud platform for deploying and hosting web applications, best known for creating Next.js and for making it easy to push code from GitHub straight to a live, fast, globally-distributed website with zero server management.

Steps 

1. Sign up / log in to Vercel with GitHub
![Login page of Vercel.png\|350](/img/user/Image/Login%20page%20of%20Vercel.png)

2. Click on Add New ->Project
![Create project.png\|700](/img/user/Image/Create%20project.png)

3. Click on Import your repository 
![Import Git Repository.png\|620](/img/user/Image/Import%20Git%20Repository.png)

4. Click on Deploy
