What is Machine Learning?
Machine Learning (ML) is a branch of artificial intelligence (AI) focused on building algorithms that learn from data and improve their accuracy over time without being explicitly programmed for every scenario.

![Machine Learning image.png\|532](/img/user/Image/Machine%20Learning%20image.png)


**Traditional Programming vs. Machine Learning**

- **Traditional Programming:** You feed **Data + Hand-coded Rules** into a computer to get **Answers**.
    
- **Machine Learning:** You feed **Data + Answers (historical results)** into a computer to output the **Rules (a Model)**.


**The 3 Main Types of Machine Learning**

|**Type**|**How It Works**|**Real-World Example**|
|---|---|---|
|**Supervised Learning**|The model trains on labeled data (input paired with the correct output).|Spam email detection, predicting house prices.|
|**Unsupervised Learning**|The model finds hidden patterns or groupings in unlabeled data.|Customer segmentation, anomaly/fraud detection.|
|**Reinforcement Learning**|An agent learns by interacting with an environment through trial, error, and rewards.|Self-driving cars, game AI (e.g., Chess, AlphaGo).|

Summary

Machine Learning (ML) is a branch of **Artificial Intelligence (AI)** that enables computers to learn from data and improve their performance without being explicitly programmed. Instead of following fixed rules, ML algorithms identify patterns in data and use them to make predictions or decisions. It is widely used in applications such as spam email detection, recommendation systems, image recognition, fraud detection, and speech recognition.
